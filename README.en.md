# 🌾 Produccions

Application for predicting agricultural production of **wheat, barley, corn, and almonds** in Catalonia.

## 📋 Description

This application lets you consult harvest predictions produced by [**IRTA**](https://www.irta.cat/programa-de-recerca/us-eficient-de-laigua-en-agricultura/) (Institut de Recerca i Tecnologia Agroalimentàries) and compare them with official data published by [**DARPA**](https://agricultura.gencat.cat/ca/departament/observatori-agroambiental/estadistiques/agricultura/estadistiques-definitives-conreus/) (Departament d'Acció Climàtica, Alimentació i Agenda Rural).

> ⚠️ **Note:** For the 2026 campaign, only IRTA's predictions are available, as DARPA's official data has not yet been published.

## 🖥️ Main application

👉 **[Open the Streamlit app](https://appuccions-mggqj6aosai4gnjz6s3epy.streamlit.app/)**

The web app allows you to:
- Consult production predictions by crop and campaign
- Compare IRTA's predictions with DARPA's official data
- Explore production trends over time

## 🌱 Crops included

| Crop | Data source |
|---|---|
| Wheat | IRTA / DARPA |
| Barley | IRTA / DARPA |
| Corn | IRTA / DARPA |
| Almond | IRTA / DARPA |
